# GUI 實驗指南

在專案根目錄執行下列命令啟動 GUI。

```powershell
.\.venv\Scripts\python.exe -m gui
```

介面包含「實驗」、「回放」、「結果」及「散布圖」頁。若電腦沒有可用 CUDA 裝置，請在每場設定的「訓練運算裝置」選擇 `CPU`。

## 建立與執行佇列

1. 在「實驗」頁選擇 `DQN`、`DQN_service`、`HRL`、`HRL_PPO` 或 `MA-CQR`。
2. 在設定表單編輯環境、訓練、評估及方法專屬欄位。欄位可搜尋，表單會依所選方法顯示相關選項。
3. 輸入實驗名稱，按「檢查設定」確認欄位有效，再按「加入佇列」。
4. 確認「輸出資料夾」後按「開始執行」。預設根目錄為 `Outputs/Experiments/`，佇列會依序執行。

選取佇列列可複製、編輯、移除或調整順序。表單的變更要按「套用編輯」才會更新選取列。進階工具可用「參數批次…」或「多欄組合…」一次建立多列，最多 100 列。佇列執行期間可匯入其他 JSON，匯入列先留在「等待中」。按「排入後續」會將所有等待中的列接在目前工作後執行。

停止會終止目前場次並略過後續工作，不會產生可接續訓練的完整 checkpoint。場次資料與錯誤日誌會保留在輸出資料夾，應查看該場的 `status.json` 與 `training.log`。

## 可調環境選項

資料到達由 `ENV.arrival_model` 選擇。預設 `always` 配合 `arrival_interval=1`，代表每個時槽固定到達。

| 到達模式 | 可調欄位 | 行為 |
| --- | --- | --- |
| `always` | `arrival_interval` | 每隔指定的正整數時槽產生資料。 |
| `bernoulli` | `arrival_probability` | 每個裝置每步獨立依指定機率產生資料。 |
| `poisson` | `arrival_rate` | 每個裝置每步依指定 Poisson 到達率產生資料。 |

通訊由 `ENV.communication_model` 選擇。預設 `snr` 使用 SNR。`sinr_hybrid` 依同頻或分時排程擇優，`sinr_adaptive` 使用固定發射功率自適應排程，`sinr_subchannels` 使用子頻道配置。SINR 相關的功率上限、固定功率與子頻道數可在環境欄位調整。

## JSON 匯入與設定範本

「載入 JSON…」可載入單場設定或 GUI 佇列 JSON。單場格式包含 `name`、`method` 及 `settings`，可參考[單場設定範例](experiment.example.json)。GUI 佇列格式包含 `experiments` 清單，可參考[佇列格式範例](../gui/experiments.example.json)。範例只示範資料結構。

匯入會把有效設定追加到目前佇列，不會清除原有列。只列出部分設定欄位時，其餘欄位使用目前預設值。佇列可包含整數 `version: 1` 和 `output_root`。閒置時匯入佇列會套用其中的 `output_root`，執行期間沿用目前輸出位置。所有列先通過驗證再加入，設定錯誤時不會加入該批 JSON。

單場設定載入後會新增一列，閒置時也可在表單中檢視及編輯。CLI worker 也支援單場設定 JSON。佇列 JSON 由 GUI 匯入。

「匯出表單 JSON…」會保存目前表單的單場設定，不會加入佇列。若要保存目前完整佇列與輸出路徑，按「儲存佇列…」。

設定範本是可重用的部分欄位。展開「進階工具（批次、範本、匯出）」後按「設定範本…」，勾選要保存的欄位並輸入名稱，再按「儲存範本」。範本保存於 `Outputs/Presets/`，該資料夾會在第一次儲存範本時建立。套用範本只會更新表單，仍需按「加入佇列」或「套用編輯」才會建立或更新佇列項目。已存在同名檔案時，GUI 會詢問是否覆寫。

## 查看結果

「結果」頁選擇含有實驗結果的資料夾並按「重新整理」。GUI 佇列預設會在輸出根目錄下為每場建立獨立資料夾，結果位於該場的 `results/` 子目錄。直接 CLI 訓練則使用指定輸出根目錄下的方法資料夾。資料夾結構及指標意義見[輸出格式](OUTPUT_FORMAT.md)。

結果頁可搜尋實驗、比較 Reward、AoI、Power、Violations 等指標、查看保存設定與日誌、載入既有設定至表單，以及匯出摘要 CSV、比較 CSV 或圖表。載入既有設定只會填入表單，不會自行啟動訓練。

## 回放軌跡

在「結果」頁選取有軌跡資料的實驗，按「觀看所選結果軌跡」可直接開啟回放。也可切換至「回放」頁，載入同一資料夾內的 `Stored_Datas/episode.parquet` 與 `Stored_Datas/step.parquet`。

回放頁可選回合、播放或逐步檢視、跳至指定步數及匯出 PNG。AoI 檢視可切換「UAV 收到的 AoI」與「裝置資料 AoI」。舊軌跡若沒有裝置 AoI 欄位，只能顯示 UAV 收到的 AoI。命令列回放方式見[CLI 指南](CLI.md#回放既有軌跡)。
