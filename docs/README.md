# 使用文件

本目錄保存專案操作手冊。方法與設定的完整選項由目前程式提供，命令列可執行 `train.py --help` 查詢。

| 文件 | 用途 |
| --- | --- |
| [ENVIRONMENT.md](ENVIRONMENT.md) | 建立 Python 環境及確認依賴 |
| [EXPERIMENTS.md](EXPERIMENTS.md) | GUI 佇列、編輯設定、範本、JSON 匯入、結果與回放 |
| [CLI.md](CLI.md) | 命令列訓練、設定覆寫、單場 worker 與軌跡工具 |
| [OUTPUT_FORMAT.md](OUTPUT_FORMAT.md) | 結果資料夾、CSV 指標、軌跡與模型檔案 |

範例 JSON 只展示格式，不代表預設實驗或推薦參數。單場設定範例在 [experiment.example.json](experiment.example.json)，GUI 佇列範例在 [gui/experiments.example.json](../gui/experiments.example.json)。
